# P1 期刊核实

1. 派 **pf-venue-verifier**（耗时较长，后台运行），产出 `venue_table.md`。
2. 抽查它给出的 2—3 个数据库链接：`python tools/cnki_title_check.py <URL…>`，篇名、刊名、年期一致才算数。
3. 向用户汇报：推荐期刊表（证据链接、适配理由、难度）、子库差异、投稿渠道核实情况、仿冒站点清单。

## 要点
- “被收录”不等于“难投”；难度看级别、每期发文量、审稿流程。
- 期刊官网列出的收录平台与第三方说法不一致时，以近一年具体篇目页面为准。
- 稿约中的硬性要求（实引页码、查重上限、制图/制谱软件、注释形式）要原样记录，后续 P3、P7、P8 都要对照。

## 闸门 G1
- [ ] 首投期刊有近一年篇目的数据库证据；
- [ ] 投稿邮箱有官方来源，或已标明“须电话核实”；
- [ ] 已记录该刊稿约的硬性要求。

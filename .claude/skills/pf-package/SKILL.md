# P8 投稿包

1. 派 **pf-packager**，或运行：
   ```
   python tools/make_package.py --src <稿件目录>/paper --name <作者-题目> --out <稿件目录>/投稿包_<期刊> --extra <源文件…>
   ```
2. 填写投稿邮件推荐文本与检查清单（期刊名称、栏目、邮箱及来源、附件、已完成项的证据、作者必做项）。
3. 用脚本输出的实际统计数字更新清单与邮件，然后**重新打包**。
4. `python tools/privacy_scan.py <投稿包目录>`。
5. 向用户汇报：zip 路径、包内文件、已完成事项、作者本人必须完成的事项（个人信息、实引页码、真实材料、查重、软件要求、官方邮箱核实）。

## 闸门 GP
- [ ] 一致性核对通过，zip 内是最新文件；
- [ ] 清单与邮件中的数字与实际一致；
- [ ] 没有代填的个人信息；投稿由作者本人完成。

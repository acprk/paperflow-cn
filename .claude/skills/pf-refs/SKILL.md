# P2 文献核实

1. 派 **pf-reference-verifier**，产出 `refs_check.md`；开放全文放入 `evidence/`。
2. 根据核查结果决定每条文献在正文中的用法：
   - 读过原文、内容对得上 → 可以挂在具体论断后，并标实引页码；
   - 只核实了题录 → 只能写“已有研究讨论过……”；
   - 未能核实 → 替换或删除（或请作者到数据库核对后保留）。
3. 专著实引页码的常用办法：作者同主题的公开期刊论文、出版社公布的目录页码、官方发布版文件的页码。

## 闸门 G2
- [ ] 每条保留的文献都有核实依据；
- [ ] 没有任何凭题名推断内容后挂上的引用；
- [ ] 所有页码都有来源，没有估填。

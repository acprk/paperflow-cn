# P0 发稿评估

1. 把原稿复制为 `原稿_<题目>.docx`（之后永不覆盖），用 `pandoc 原稿.docx -t plain` 转文本。
2. 派 **pf-intake-evaluator**，或自己按其清单逐项检查：引用标注与出处、专业表述、重复与错别字、套话词频、未经验证的断言、作者简介与篇幅。
3. 填写 `templates/eval_report.tex`，`xelatex` 编译两遍；渲染页面图片抽查版式（表格跨页可用 xltabular）。
4. 向用户汇报：结论（是否达标、能否改到达标）、必须修改项、建议修改项、工作量、需要作者提供的材料。

## 闸门 G0（进入 P1 之前）
- [ ] 每个问题都引用了原句并给出依据；
- [ ] 费用一节只写“以期刊录用通知为准”，没有报价或包发表承诺；
- [ ] 若评估说明本身有误，已出更正版。

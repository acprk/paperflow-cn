# P6 查新与挖掘

1. 用 `prompts/mining.md` 跑 Codex（只读，不读以往意见）；可并行派 **pf-novelty-miner** 做独立查新。
2. 核实审稿组列出的近邻文献：逐篇打开题录页，确认作者、题名、刊名、年期、页码、摘要。
3. 核实其他事实性意见（例如版本史、原文页码），找到一手来源后才采纳。
4. 修改（交 P3）：
   - 引言补“与最相近研究的比较 + 本文增量”的定位句；
   - 补质量标准、示例或贯穿性任务，使主张有具体材料支撑；
   - 无法由助手补齐的真实材料，写进作者待办。
5. 用 `prompts/mining_followup.md` 复核，直到没有新的确定问题。

## 闸门 G5
- [ ] 最相近研究已在正文中如实回应；
- [ ] 采纳的每条事实性意见都有一手来源；
- [ ] 反方审稿人的“确定问题”已解决或列为作者待办。

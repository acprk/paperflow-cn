# Codex 审稿提示词模板

每个模板中的 `{{…}}` 是占位符：

| 占位符 | 含义 |
|---|---|
| `{{JOURNAL}}` | 目标期刊名称及栏目 |
| `{{MANUSCRIPT}}` | 稿件纯文本路径（由 pandoc 从 Word 导出） |
| `{{ORIGINAL}}` | 原稿纯文本路径（首轮对比用） |
| `{{STYLE_GUIDE}}` | 期刊体例说明（venue_table.md 中对应条目或稿约链接） |
| `{{PREV_REVIEW}}` | 上一轮审稿意见文件 |
| `{{EVIDENCE_DIR}}` | 原始证据目录（原文 PDF 转出的 txt、乐谱/图表扫描、数据等） |
| `{{FILE:路径}}` | 由 `tools/inline_prompt.py` 替换为该文件的全文（当 Codex 沙箱读不到文件时使用） |

## 使用顺序

| 阶段 | 模板 | 目的 |
|---|---|---|
| P4 第一轮 | `review_round1.md` | 编辑 + 两位外审，逐条核对评估说明中的问题，给录用估计 |
| P4 后续轮 | `review_followup.md` | 同一审稿组复审：问题是否解决、有无新错误 |
| P5 | `expert_factcheck.md` | **全新**审稿组，逐句核查专业事实，不读以往意见 |
| P5 确认 | `factcheck_confirm.md` | 核对 P5 的问题是否正确修改 |
| P6 | `mining.md` | 主编查新 + 专业 + 理论 + 反方审稿人，挖掘未发现的问题 |
| P6 复核 | `mining_followup.md` | 核对挖掘出的问题的处理情况 |
| P7 | `final_check.md` | 体例合规清单 + 语言自然化建议 |

运行：`tools/run_codex.sh <稿件工作目录> <填好的提示词.md> reviews/CODEX_xx.md`

## 共同要求（已写进每个模板）
- 只读：审稿人不修改任何文件；
- 每个问题必须给出原句、依据（链接/原文页码，或标明“经验判断”）和可替换文本；
- 区分“确定的问题”和“可商榷之处”，不为凑数挑刺；
- 录用可能性只能是主观估计，不得伪装成统计数据。
